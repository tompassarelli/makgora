# fixture:fox links

Generated by `bun wisp combos --links --fighter fixture:fox`; do not edit. Each opener hit, by region class, lands on Rifleman at the stage's centre with its weight set to 60, 75, 100, 143 (Melee units; Fox is 75), at 0–150% before the hit, under DI out, up, down, in, none. For each follow-up the combo explorer's attacker inputs are searched for a hit that lands at most 12 frames after the victim can act, and the 4 earliest are replayed against every victim option of the agency measure that changes where the victim ends up.

Classes, over the DIs the opener does not kill through: T true (every DI and every option is hit), DI DI-dependent (only some DI escape), R read (an option other than DI escapes), · none (no DI lets it land). Frame advantage is the victim's first actionable frame minus the attacker's, without DI; KO marks an opener that takes the stock without DI. The rows in the `.jsonl` beside this page add each follow-up's input, contact frame and escapes.

No setup lands a hit with neutral special, side special, up special, down special, so they have no rows.
