# Classic mode

Classic was replaced by Arcade (makgora#1133): one fixed run of 8 stages for
every featured fighter, with the run engine in `ts/src/game/arcade/`. The
design, tiers, run structure and per-fighter tables are in
makgora:docs/design/arcade-mode.md. Classic's 28 per-fighter routes, its
health-bar bosses and its route and ending lines were removed with it.
